# WebUI 设计约定

适用于本仓库的 LoRA 数据工作台。设计参考 ChatGPT / Codex 网页的克制、清晰与内容优先，不复制聊天产品的页面结构。以下为已确认的项目约束；最新用户要求优先，当前实现值以 [theme.css](../../../../app/src/theme.css) 为准。

## 配色与层级

- 以白、黑、中性灰构建界面；不使用绿色、带绿倾向的灰色、彩色强调或装饰渐变。图片内容本身不受色板限制。
- 页面底、面板、悬停与选中状态通过灰阶区分。主要动作使用深灰底白字；次要动作使用浅底、细边框。避免多个高对比按钮争夺注意力。
- 选中态保留深色边框、字重或勾选标记，悬停不能覆盖选中提示。键盘焦点使用清晰的深色轮廓。
- 分隔线与输入边界分别使用语义 token；错误和风险提示保留有效文字与字重，不能因去色而变得不可辨认。
- 阴影仅用于浮层等需要表达层级的地方，普通面板用细边框，不增加玻璃效果或多层卡片。

当前基础 token（不应复制成组件中的硬编码）：

| 用途 | token 后缀（前缀为 `--color-review-`） | 当前值 |
| --- | --- | --- |
| 主文字、主要动作 | ink、accent | `#262626` |
| 次要文字 | muted | `#666666` |
| 页面底、面板 | canvas、surface | `#fafafa`、`#ffffff` |
| 分隔线、输入边界 | line、field-line | `#e5e5e5`、`#b3b3b3` |
| 控件边界、浅灰状态面 | control、tint | `#a3a3a3`、`#f0f0f0` |
| 主按钮悬停 | accent-hover | `#404040` |

## 布局与留白

- 仅面向桌面。保留顶部导航、各 tab 的主体分栏、已有滚动区域和工作顺序；不要自行改成侧栏导航或营销落地页。
- Header 和普通主体采用 `--review-page-gutter: clamp(24px, 3vw, 48px)`。同一横向路径只由一层承担外部 padding，不层层累加。已有内容宽度上限与居中关系继续保留。
- **裁切和标签编辑主体不增加外层左右 padding**，优先保留画布、缩略图和编辑控件的可用空间。其数据集栏使用独立的 `--review-editor-gutter`；控件内部必要间距不必删除。
- 目录、当前数据集全部图片范围、批量超分和主体识别操作采用紧凑单行；长目录可省略并通过悬停查看全文。用弹性布局和容器滚动应对桌面窗口变化，不新增移动端或平板断点。
- 普通裁切画布上方不恢复“工作图 · 拖动裁框移动，拖动角点缩放”说明行。画布使用腾出的高度；主体裁切模式现有的操作提示按当前源码保留。

## 字体与组件

- 沿用系统无衬线字体，路径等内容可用已有等宽字体。避免引入装饰字体、过多字号或大写字距。
- 普通页面标题沿用 24px token 与适度字重；密集编辑区保留较小标题。首页现有大标题和双栏构图保持，不为模仿 ChatGPT 首页强制缩小或重排。
- 控件圆角使用 `--review-radius`（8px），面板使用 `--review-panel-radius`（12px）；复用现有分层，不任意混入其他圆角风格。
- 顶部 tab 使用轻量文字和浅灰选中面，主按钮用黑白对比，避免恢复彩色下划线。
- 裁框使用白线与黑色阴影保证图片上的辨识度；不得为了样式改变图片坐标、裁框边界或拖动逻辑。

## 文案与信息密度

- 删除无操作价值的英文眉题、角落标语、装饰页脚和重复标题，例如 `DATASET WORKSPACE`、`OPEN DATASET`。不要把删掉的文字换一种装饰形式加回来。
- 保留组件 label、数据集路径、图片分辨率、任务状态、错误、操作范围及影响决策的说明。不能把“清理小字”理解为删除所有辅助信息。
- 详细处理规则放在对应按钮旁的“？”tooltip 中，支持悬停和键盘聚焦；简短处理范围仍常驻。超分阈值等业务参数从当前实现核对，不在 skill 中固定为永久规则。
- 裁切与标签页不再展示身份筛选，也不展示“切换数据集”按钮；数据集选择集中在主页。这是已确认的界面安排，不代表可以删除底层身份字段或改变筛选协议。

## 范围与验证

- 默认只调整视觉和明确指定的展示内容。保存反馈、自动保存、快捷键、切图保护、更多菜单等交互修改必须来自用户的任务授权；此前讨论过的建议不能视为已批准。
- 先按项目功能导航核对相关实现，沿用 CSS Modules、主题 token 与现有组件结构，不重建一套并行设计系统。
- 小调整做针对性格式与差异检查；涉及布局时在适当桌面尺寸检查溢出、画布可用空间、焦点和 tooltip，前端代码按改动范围执行构建。
- 临时示例数据的浏览器检查与真实数据、模型运行分别报告；不要为视觉验证启动超分、识别、打标或导出。
