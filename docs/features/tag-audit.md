# 打标后标签异常检查

[返回功能导航](../feature-map.yaml)

核对日期：2026-11-07。覆盖标签页入口、后台检查、观察协议、人工应用、忽略与批次撤销。属于一次打标后的辅助检查，不重新打标、不调整融合阈值、不自动重写 caption。

## 入口和实现

- [TagEditor](../../app/src/Pages/review/ReviewPage/__internal__/TagEditor/TagEditor.tsx)：标签工具中的“标签检查”入口；可返回原标签编辑。
- [TagAudit](../../app/src/Pages/review/ReviewPage/__internal__/TagAudit/TagAudit.tsx)：数据集级配置、类型/状态筛选、图片与删除建议并列、单项/批量应用、保留原标签、失败/不确定样本和批次撤销。
- [tag_audit.py](../../core/dataset_pipeline/tag_audit.py)：验证配置和模型观察、从事实生成异常、结果新鲜度判定、写入与撤销。记录保存在当前运行 `tag_audit`，与打标分数分开。
- [server.py](../../webui/server.py)：`start_audit` 使用现有后台任务、运行锁与会话校验；`apply_audit`、`ignore_audit`、`undo_audit` 与其他写入互斥；`/api/state` 计算待处理/已忽略结果是否过期。

## 检查协议和范围

范围固定为当前数据集活跃、已接受且标签有效的样本，不随标签页筛选与勾选变化。直接读取 `tag.image` 对应训练样本，EXIF 校正并转换 RGB，等比例限制长边至 1536 后发送。使用用户配置的本机 HTTP `/chat/completions` 兼容接口，不跟随重定向，不使用环境代理，不启动 Forge。地址应包含服务需要的 `/v1` 前缀；默认填入本机 `http://localhost:23333/v1` 和 `lfm3-vl-2b`，可在页面修改，随检查保存到数据集。

模型输入只有图片和固定观察问题，不携带已有标签及 tagger 分数。返回人数、可判定的男女人数、构图范围、确定性与简短视觉依据；程序检查人数标签、`solo`、`no humans` 及有限构图冲突。未知性别不强行推断数量标签，不确定观察不生成该类别的删除建议。第一版只建议删除，不自动添加替代标签。

身份/来源类使用用户明确填写的当前数据集禁用标签，按规范化后的完整标签匹配；不凭图片推断作品和角色是否属于 VTuber。禁用列表默认空；可关闭视觉检查，仅执行规则。视觉服务失败时仍保存本图规则结果，并报告失败，不将失败/拒答/截断输出当作“无异常”。

## 人工决定与写入

运行检查不修改工作 TXT。应用只删除明确选中的标签，保留其他内容；单项应用也作为一个批次。忽略仅记录“保留原标签”，同一图片与相关标签未变化时重复检查不再提醒。图像版本（标签键、路径、裁框、文件尺寸和修改时间）或相关类别标签变化后，待处理和已忽略项显示过期，拒绝应用。

每个应用批次保存样本前后标签及图像版本。撤销要求图片和当前标签仍与该批次应用后快照一致；有后续编辑时拒绝覆盖，可以先撤销后续批次。写入异常会尝试恢复受影响 TXT 与记录；不承诺跨文件的断电事务。导入来源图片和 TXT 不写入。

## 验证入口

[test_tag_audit.py](../../tests/test_tag_audit.py)：合成图片与模拟模型响应，聚焦检查不写 TXT、真实 HTTP 后台任务的应用/忽略/撤销、逐项决策、标签过期与后续编辑保护，以及不确定观察、服务失败和写入回滚。模型判断准确率需另用代表性真实图片验证；合成图上的真实模型调用只验证服务接入及有限行为。
